```html Our Little Pinboard ♡

finding your pictures ♡
``` ### What changed **No more fixed 650×650 positioning.** Each photo's actual dimensions are calculated first, and the next frame is placed after the previous frame. So a portrait, landscape, or weirdly shaped image won't overlap another frame. **No cropping:** the image uses `object-fit: contain`, and the frame itself is calculated from the image's aspect ratio. The entire picture is visible. **New loading screen:** dark romantic background, subtle stars, floating hearts, pulsing heart, progress bar, and a little `"our little memories"` message. And importantly, **you don't need to change the filenames again**. The GitHub discovery code finds the actual image files in the repo rather than us guessing the numbering pattern.
